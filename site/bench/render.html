Renderer bench

The two canvas renderers in web/src/render.ts, timed on synthetic frames: text (fillText per changed cell) and atlas (white glyph masks from an atlas keyed by code point alone, tinted by compositing a one-pixel-a-cell colour image). The owner's Chrome and Safari numbers choose the renderer (REQ-RENDER-050); the colour ratio is REQ-RENDER-010's check.

How to run it

  1. mise run bench:render serves this page and prints its URL. Add -- --host to reach it from another device on the network.
  2. Desktop: mains power, other tabs and apps closed, the window on the built-in or main display. Chrome: chrome://gpu must say "Canvas: Hardware accelerated". Safari: Develop menu off its defaults; no Web Inspector open while it runs.
  3. Open this page in Chrome, press Run, wait until the table appears (about a minute), and copy it. Then the same in Safari. Phones: the same over --host.
  4. Put both tables, the browser versions and the machine in the plan's "Renderer" section; the renderer with the lower frame times on both browsers becomes config.renderer's default in web/src/element.ts.

Each case draws 10 warm-up frames and then 60 timed ones; a frame's time is the draw plus a one-pixel getImageData, which waits for the raster (draw calls are otherwise deferred). A run takes each case's median and 95th percentile; the table gives the minimum and the median of the runs' medians. ?runs=N sets the runs (default 3).
