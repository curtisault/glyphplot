Live candles simulated

A seeded synthetic feed (site/feed.ts), not market data: 5-second candles, a tick every 250 ms appended with element.append, the forming candle replaced in place. Open this page on a phone over a throttled network and scrub with a finger; the network panel shows one wasm module, candles.

Serve it, don't open the file: mise run serve -- --host serves the release build at http://<this machine>:4311/live.html (mise run serve alone for this machine only). mise run dev serves it too, but from the debug build, whose one module plays every chart.
