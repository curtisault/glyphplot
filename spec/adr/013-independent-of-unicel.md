# ADR-013: Independent of unicel

Status: Accepted (2026-10-18)

## Context

glyphplot takes unicel's architecture (ADR-003) and grew out of unicel's three
data pieces. Discovery found that glyphplot needs much of what unicel's core
already holds (a grid of code points, sub-cell canvases, glyph tables, block
shapes, a subset font, a loader, a CLI) and weighed three ways to get it
(`discovery/rendering.md` §1.1, [ADR-100](100-vendor-unicels-core.md)):

- depend on a unicel core crate, which does not exist on crates.io and would
  have to be split out and published first;
- a git dependency on unicel's repository, which crates.io refuses for a
  published crate;
- vendor about 1,240 lines of unicel's Rust, its `blocks.ts`, its font and its
  font script, with provenance headers.

Discovery recommended vendoring. A fourth way is to share nothing: glyphplot
writes every layer itself, from the Unicode Standard, the fonts' upstream
releases and its own design, with unicel cited as prior art as uPlot and
ratatui are.

## Decision

glyphplot is a distinctly separate and independent project. Nothing in its
repository is copied, ported, vendored or generated from unicel's repository
(`../animate-unicode`), and no crate, package, script or task depends on it or
reads from it (REQ-INDEP-010, REQ-INDEP-020). In particular glyphplot writes its
own:

- grid and sub-cell canvases (REQ-GRID-010 to 070, REQ-CANVAS-010 to 040),
  with glyph encodings taken from the Unicode Standard and the octant table
  generated by its own script from `UnicodeData.txt`;
- block shapes, renderer, loader, manifest, element and shell;
- font build, subsetting Iosevka from its upstream release (REQ-FONT-010);
- terminal glyph fallback, CLI, snapshot format code, signoff script.

unicel stays prior art: its design, its spec and discovery's measurements of
its code may be cited, as any library's may. ADR-100 is rejected.

## Consequences

- Phases 0 and 1 write what would have been vendored: about 1,240 lines of
  Rust and 55 of TypeScript by discovery's count, plus the octant table
  script and the font script. The plan's phase tasks say so.
- Requirements that pointed into unicel's spec are restated in full in
  `spec/ROADMAP.md`, so glyphplot's spec can be read without unicel's.
- Sizes discovery measured on unicel's code (the grid and braille canvas at
  3,043 B gzipped over an empty module) are estimates for glyphplot's own code
  **(unverified)** until Phase 0 measures them.
- A fix in one project never reaches the other; the two may drift freely.
- Unit tests pin glyphs against Unicode character names, not against unicel's
  tests.
