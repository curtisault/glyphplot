# ADR-128: Fixtures generated from seeds

Status: Proposed (2026-10-18)

## Context

ADR-006 requires fixture datasets to be generated deterministically or checked
in, never fetched. The contract runs every chart over fixtures from an empty
series to a million rows (`discovery/testing.md`, Fixture datasets). The two
million-row fixtures are 16 MB each as `f64`. testing.md D5 weighed:

- **(a) Generate in Rust from seeds**, written to `target/` for the Node tests.
- **(b) Check them in**, perhaps with Git LFS.
- **(c) Generate in both Rust and JavaScript** from the same PRNG.

Measured in testing.md M4 (native release, 7 timings a step, three runs at
load 5.72):

- All 14 fixtures of the bench: 1.053–1.158 ms, the sum of medians.
- `random-walk-1m` alone: 0.862–0.962 ms min.
- SplitMix64 is ten lines and gives the same stream on every target.

(c) needs two generators that must agree bit for bit. Real data still matters
for snapshots that look like what users see; `discovery/domains.md` found
public-domain series small enough to commit: the 2026 Treasury par yield curve
is 16,229 B (EIA WTI and a USGS excerpt are the others it names).

## Decision

- Fixture datasets are generated by `crates/glyphplot/src/fixtures.rs` from
  SplitMix64 with a fixed seed each, include the 23 fixtures of the plan's
  table, and two generations are bitwise equal on every target (REQ-FIX-010).
- The Node tests read fixtures that a cargo example writes into `target/`; the
  Rust generator is the one source.
- Real datasets checked in under `crates/glyphplot/tests/data/` are each under
  100 KB, public domain or MIT-compatible, named with source and licence in
  that directory's README (REQ-FIX-020): EIA WTI daily, the Treasury yield
  curve and a USGS earthquake excerpt.
- No million-row fixture is checked in.

## Consequences

- The repository stays small and the fixtures cost about a millisecond.
- The Node tests need the cargo step before they run.
- A change to a seed or the generator changes every snapshot that uses it, so
  both are frozen once snapshots exist.
